Consider the following TRC expression: {T.name | T in Students AND T.age > 20 AND exists E(E in Enrollment AND E.student = T.name AND E.grade = "A")} Which of the following SQL queries is equivalent?
  • A)SELECT name FROM Students WHERE age > 20 AND name IN (SELECT student FROM Enrollment WHERE grade = "A")Correct
  • B)SELECT name FROM Students, Enrollment WHERE age > 20 AND grade = "A"
  • C)SELECT DISTINCT name FROM Students WHERE age > 20 OR grade = "A"
  • D)SELECT name FROM Students WHERE age > 20 UNION SELECT student FROM Enrollment WHERE grade = "A"
Correct answer: A) SELECT name FROM Students WHERE age > 20 AND name IN (SELECT student FROM Enrollment WHERE grade = "A")
